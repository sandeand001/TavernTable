Contents: one FBX model source and seven color variants with BaseColor, Normal,
Roughness and Height maps at 2048x2048. The creator describes each six-die set as
62 vertices / 100 triangles; the complete seven-variant preview is 700 triangles.

The original FBX and textures remain source-only. A normalized runtime model
with seven reduced-resolution color sets is integrated for player d4, d6, d8,
d10, d12 and d20 rolls. The existing gold d20 remains the DM physical die.
The runtime implementation calibrates face mappings and colliders, supports
deterministic replay, and retains the attribution in the application notices.
